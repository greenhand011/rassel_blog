# Blog Publish Review Checklist

- Frontmatter exists and includes `title`, `date`, `tags`, `draft`, `summary`.
- Date format is consistent and parseable.
- The article reads like a real author’s technical note, not an AI summary.
- Every `<img src="/static/images/...">` points to an existing file.
- Only the images that are actually used were renamed.
- Image placement matches the nearby explanation.
- Code snippets, commands, and logs are accurate to the source note.
- No invented test results, measurements, or screenshots.
- Unrelated files were not staged.
- If git delivery was requested, commit and push happened after validation.
