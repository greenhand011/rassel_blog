## Part 0: 工欲善其事（CVXPY 环境配置）

在开始做数学题之前，建议先装好 Python 优化工具 **CVXPY**。这不仅能帮你验证简单的优化问题，也是后续课程作业的刚需。

**快速安装命令（推荐使用 Conda）：**

```bash
# 1. 创建环境
conda create --name cvxpy_env python=3.9
# 2. 激活环境
conda activate cvxpy_env
# 3. 安装 CVXPY
conda install -c conda-forge cvxpy
```

**测试代码：**
跑通下面这个简单的最小二乘法代码，说明环境没问题：

```python
import cvxpy as cp
import numpy as np

# 生成数据
m, n = 20, 15
np.random.seed(1)
A = np.random.randn(m, n)
b = np.random.randn(m)

# 求解 ||Ax - b||^2
x = cp.Variable(n)
cost = cp.sum_squares(A @ x - b)
prob = cp.Problem(cp.Minimize(cost))
prob.solve()

print(f"Optimal value: {prob.value:.4f}")
```

## Part 1: 基础凸性证明 (Q1 - Q3)

这三道题考察凸集定义的灵活运用：**“两点连线在集合内”**。

### Question 1: 凸组合 (Convex Combination)

**题目**：证明 $k$ 个点的加权平均（权重和为1，且非负）依然在凸集 $C$ 内。

<img src="/static/images/Optimization/T1Q1.png" alt="第一题" width="700" />
**解析**： 这是凸集定义的推广。

- **$k=2$ 时**：直接就是凸集定义，显然成立。
- **$k > 2$ 时**：使用**数学归纳法**。
  - 假设 $k=m$ 时成立。
  - 当 $k=m+1$ 时，把第 $m+1$ 个点分离出来：
    $$ y = \theta*1 x_1 + ... + \theta*{m+1} x*{m+1} $$
    令 $\lambda = \sum*{i=1}^m \theta*i = 1 - \theta*{m+1}$。
        $$ y = \lambda \underbrace{\left( \sum*{i=1}^m \frac{\theta_i}{\lambda} x_i \right)}*{\text{归纳假设: 在 C 中}} + \theta*{m+1} x*{m+1} $$
  - 这就变成了“前 $m$ 个点的组合点”与“第 $m+1$ 个点”的**两点凸组合**。根据定义，$y \in C$。

### Question 2: 交集的凸性

**题目**：证明任意多个凸集的交集 $\bigcap C_\alpha$ 依然是凸集。

<img src="/static/images/Optimization/T1Q2.png" alt="第二题" width="700" />
**解析**：

- **直觉**：两个圆形重叠，中间的杏仁形状也是凸的。
- **证明**：
  1.  从交集中取两点 $x, y$。这意味着 $x, y$ 属于**每一个**子集 $C_\alpha$。
  2.  因为每个 $C_\alpha$ 都是凸的，所以 $x, y$ 的连线也在每个 $C_\alpha$ 里。
  3.  既然连线属于每一个 $C_\alpha$，那它自然属于它们的交集。证毕。

### Question 3: 直线与凸集

**题目**：证明一个集合是凸集，当且仅当它与任意直线的交集是凸集。

<img src="/static/images/Optimization/T1Q3.png" alt="第三题" width="700" />
**解析**：

- **$(\Rightarrow)$ 正向**：如果你切西瓜（凸集），切面上的线段（交集）肯定也是直的（凸的）。
  - 证明：直线是凸集，$C$ 是凸集，根据 Q2，两个凸集的交集一定是凸集。
- **$(\Leftarrow)$ 反向**：如果每一刀切下去都是凸的，那原物体就是凸的。
  - 证明：在 $C$ 中任取两点 $x, y$。构造一条穿过 $x, y$ 的直线 $L$。
  - 已知 $C \cap L$ 是凸集，且 $x, y$ 都在这个交集里。
  - 根据凸集定义，线段 $xy$ 必须在这个交集里，也就是在 $C$ 里。证毕。

## Part 2: 谁是凸集？ (Question 4)

这道题考察你的**火眼金睛**。判断集合是否为凸，核心秘诀是看它能否由**半空间（线性不等式）**、**球**等基本凸集通过交集等保凸运算得到。

<img src="/static/images/Optimization/T1Q4.png" alt="第四题" width="700" />

**(a) A slab (板状区域): $\{x \mid \alpha \le a^T x \le \beta\}$**

- **判定**：✅ 凸集
- **理由**：这是两个半空间 $a^T x \ge \alpha$ 和 $a^T x \le \beta$ 的**交集**。

**(b) A rectangle (矩形): $\{x \mid \alpha_i \le x_i \le \beta_i\}$**

- **判定**：✅ 凸集
- **理由**：这是 $2n$ 个半空间的交集（每个维度两个约束）。

**(c) A wedge (楔形): $\{x \mid a_1^T x \le b_1, a_2^T x \le b_2\}$**

- **判定**：✅ 凸集
- **理由**：两个半空间的交集。

**(d) Points closer to a given point than a set**

- **集合**：$\{x \mid \|x - x_0\|_2 \le \|x - y\|_2, \forall y \in S\}$
- **判定**：✅ 凸集 (Voronoi 区域)
- **理由**：我们把不等式平方展开：
  $$ \|x\|^2 - 2x^T x_0 + \|x_0\|^2 \le \|x\|^2 - 2x^T y + \|y\|^2 $$
    $$ 2x^T (y - x_0) \le \|y\|^2 - \|x_0\|^2 $$
    对于每一个固定的 $y$，这都是一个关于 $x$ 的**线性不等式**（半空间）。
  整个集合是无穷多个半空间的**交集**，所以是凸集。

**(e) Points closer to one set than another**

- **集合**：$\{x \mid \text{dist}(x, S) \le \text{dist}(x, T)\}$
- **判定**：❌ **不一定是凸集**
- **反例**：设 $S=\{0\}$ (原点)，$T=\{10, -10\}$ (两点)。
  距离原点比距离 $\pm 10$ 更近的区域是 $(-5, 5)$。
  但如果 $S$ 是圆环边界，$T$ 是圆心，区域可能是个环形，不是凸的。除非 $S$ 和 $T$ 有特殊性质，否则一般不是。

**(f) Set erosion: $\{x \mid x + S_2 \subseteq S_1\}$ ($S_1$ is convex)**

- **判定**：✅ 凸集
- **理由**：这是 Minkowski Difference。
  设 $x, y$ 在集合中，即 $x+s \in S_1, y+s \in S_1$ ($\forall s \in S_2$)。
  考虑组合点 $z = \theta x + (1-\theta)y$。
  $$ z + s = \theta(x+s) + (1-\theta)(y+s) $$
    因为 $S_1$ 是凸的，且 $x+s$ 和 $y+s$ 都在 $S_1$ 里，所以它们的凸组合 $z+s$ 也在 $S_1$ 里。证毕。

**(g) Distance constraint: $\{x \mid \|x - a\|_2 \le \theta \|x - b\|_2\}$ ($0 \le \theta \le 1$)**

- **判定**：✅ 凸集
- **理由**：
  两边平方：$\|x-a\|^2 \le \theta^2 \|x-b\|^2$。
  展开整理后，项 $(1-\theta^2)\|x\|^2$ 的系数是非负的（因为 $\theta \le 1$）。
  - 若 $\theta = 1$：变成线性不等式（半空间）。
  - 若 $\theta < 1$：变成一个球体内部（Apollonius circle）。
    两者都是凸集。

## Part 3: 几何计算与多面体 (Q5 - Q6)

### Question 5: 平行超平面间的距离

**题目**：求 $\{x | a^T x = b_1\}$ 和 $\{x | a^T x = b_2\}$ 的距离。

<img src="/static/images/Optimization/T1Q5.png" alt="第五题" width="700" />
**解析**： 公式大家高中可能背过，这里用向量法推导：

1.  在平面 1 上任取一点 $x_1$。
2.  点 $x_1$ 到平面 2 的距离公式为 $d = \frac{|a^T x_1 - b_2|}{\|a\|_2}$。
3.  因为 $a^T x_1 = b_1$，直接代入得：
    $$ \text{Distance} = \frac{|b_1 - b_2|}{\|a\|\_2} $$

### Question 6: 谁是多面体 (Polyhedra)?

<img src="/static/images/Optimization/T1Q6.png" alt="第六题" width="700" />

**多面体定义**：有限个线性等式和不等式的解集 $\{x \mid Ax \le b, Fx = g\}$。
_换句话说，边界必须是平直的，不能是弯曲的。_

**(a) $S = \{y_1 a_1 + y_2 a_2 \mid -1 \le y_i \le 1\}$**

- **判定**：✅ 是多面体
- **理由**：这是一个平行四边形（二维）或其高维嵌入。它是线性变换后的盒子，依然由线性不等式围成。

**(b) $S = \{x \ge 0, \mathbf{1}^T x = 1, \sum a_i x_i = b_1, ...\}$**

- **判定**：✅ 是多面体
- **理由**：所有的约束（$x \ge 0$，求和等式）全部都是线性的。这是概率单纯形切了两刀，依然是多面体。

**(c) $S = \{x \ge 0, x^T y \le 1 \text{ for all } \|y\|_2 = 1\}$**

- **判定**：❌ **不是多面体**
- **理由**：条件 $x^T y \le 1, \forall \|y\|_2=1$ 等价于 $\sup x^T y \le 1$，即 $\|x\|_2 \le 1$（对偶范数）。
  集合实际上是 $\{x \mid x \ge 0, \|x\|_2 \le 1\}$，即**八卦限里的四分之一球**。球的边界是弯的，不是多面体。

**(d) $S = \{x \ge 0, x^T y \le 1 \text{ for all } \sum |y_i| = 1\}$**

- **判定**：✅ 是多面体
- **理由**：条件 $\sum |y_i| = 1$ 是 $L_1$ 范数单位球。
  其对偶条件是 $L_\infty$ 范数 $\|x\|_\infty \le 1$，即 $\max |x_i| \le 1$。
  结合 $x \ge 0$，这实际上是一个**单位立方体** $\{x \mid 0 \le x_i \le 1\}$。立方体是多面体。

## Part 4: 二次不等式的凸性 (Question 7)

**题目**：$C = \{x \mid x^T A x + b^T x + c \le 0\}$。

<img src="/static/images/Optimization/T1Q7.png" alt="第7题" width="700" />

**(a) 证明若 $A \succeq 0$ (半正定)，则 $C$ 是凸集。**

- **证明**：
  若 $A \succeq 0$，则函数 $f(x) = x^T A x + b^T x + c$ 是**凸函数**（二阶导 $2A$ 非负定）。
  凸函数的**下水平集 (Sublevel Set)** $\{x \mid f(x) \le 0\}$ 永远是凸集。证毕。

**(b) 证明若 $A + \lambda g g^T \succeq 0$，则 $C$ 与超平面 $g^T x + h = 0$ 的交集是凸的。**

- **直觉**：
  也许 $A$ 本身不是半正定的（比如 $x^2 - y^2 \le 1$ 是双曲线，非凸），但我们被限制在一条直线上。只要在这条直线上它是“弯向上”的就行。
- **证明**：
  在超平面 $g^T x = -h$ 上，满足约束的点 $x$ 使得 $g^T x$ 是常数。
  考虑函数 $f(x) = x^T A x + b^T x + c$。
  构造新函数 $\tilde{f}(x) = x^T (A + \lambda g g^T) x + b^T x + c$。
  在超平面上，$\lambda (g^T x)^2 = \lambda (-h)^2$ 是个常数！
  所以 $f(x)$ 和 $\tilde{f}(x)$ 在超平面上只差一个常数，它们的凸性是一样的。
  因为 $A + \lambda g g^T \succeq 0$，所以 $\tilde{f}(x)$ 是全局凸函数。
  其下水平集与超平面的交集自然也是凸的。

## 总结

恭喜你！你已经刷完了 Tutorial 1 的所有题目。回顾一下重点：

1.  **定义法**：$k$ 点凸组合、直线交集、Minkowski 差集，回归 $\theta x + (1-\theta)y$。
2.  **积木法**：把集合看作半空间、球、超平面的交集（如 Slab, Wedge, Voronoi, Rectangle）。
3.  **范数法**：$L_2$ 球是圆的（非多面体），$L_1, L_\infty$ 球是方的（多面体）。
4.  **Hessian 法**：二次型 $x^T A x$ 只要 $A$ 在约束方向上正定，就是凸的。
